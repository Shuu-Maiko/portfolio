# Getting Started

Step-by-step guide to setting up the **Swiss Journal** portfolio on your local machine.

## Prerequisites

Ensure you have the following installed:
- **Node.js** (v18.0.0 or higher)
- **npm** or **pnpm** (preferred)

## Installation Steps

1. **Clone the Repository**
   ```bash
   git clone <your-repo-link>
   cd pfolio
   ```

2. **Install Dependencies**
   ```bash
   npm install
   # or
   pnpm install
   ```

3. **Environment Setup**
   The project is designed to be plug-and-play. No complex `.env` is required for the core UI, though you may add one later for analytics or head-less CMS integration.

4. **Run the Development Server**
   ```bash
   npm run dev
   ```

5. **Access the Application**
   Open [http://localhost:3000](http://localhost:3000) in your browser.
